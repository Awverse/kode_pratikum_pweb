Console Dasar JavaScript

Kode JavaScript Anda telah berhasil dihubungkan! Karena kode ini bersifat console dasar, Anda perlu membuka fitur pengembang di browser untuk melihatnya.

Cara Melihat Hasil:

  1. Klik kanan di halaman web ini, lalu pilih Inspect (atau Inspeksi).
  2. Pilih tab Console pada panel DevTools yang muncul.
  3. Lihat hasil perhitungan dari file script.js milikmu!
