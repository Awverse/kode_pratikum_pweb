Praktikum Pemrograman Web

Membangun halaman web responsif menggunakan komponen siap pakai dari Bootstrap versi 5 untuk laporan untuk Program Studi Sistem Informasi.

Bootstrap Grid

Mengatur tata letak kolom dan baris secara fleksibel di berbagai ukuran layar.

Komponen UI

Memanfaatkan tombol, navbar, dan kartu (*card*) instan yang elegan.

Responsif

Tampilan otomatis menyesuaikan perangkat *mobile*, *tablet*, hingga *desktop*.

Pengembangan Antarmuka Web

Bootstrap mempermudah dalam merancang antarmuka website tanpa harus menulis kode CSS manual dari nol.

Fokus utama percobaan meliputi keberhasilan membuat landing page menggunakan Bootstrap 5.
